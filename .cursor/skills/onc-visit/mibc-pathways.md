# MIBC Decision Pathways (Onc Visit)

Use with PubMed-verified evidence. Re-run trial searches before recommending contemporary perioperative standard of care.

## Branch 0 — Always first when hydronephrosis or renal dysfunction

```
Obstruction present?
  → Yes: ureteric stent (preferred when feasible) or PCN
  → Restage (MRI pelvis ± CT/PET)
  → Recalculate GFR; reassess cisplatin vs carboplatin vs ineligible
  → MDT
  → Then enter Branch A, B, or C
```

**Report requirement:** Section 3 (pre-definitive) must spell out this branch even if the user only asked about "management."

**Sourced cautions to mention when applicable:**
- Hydronephrosis: adverse prognostic marker for RC, TMT, and bladder preservation (meta-analytic HR ~1.65 OS in TMT; CSS HR ~2.0 in RT-based preservation).
- Bilateral hydronephrosis: worse OS/DSS than unilateral after RC (Canter 2008).
- PCN before NAC: lower adequate NAC completion, more infections/hospitalizations (Savin 2024).
- Hydronephrosis predicts pathologic upstaging (OR ~2.24) and occult nodal risk.

## Branch A — M0, RC-feasible

### A1 Cisplatin-eligible
**Preferred (contemporary):**
- Neoadjuvant durvalumab + gemcitabine–cisplatin ×4 → RC + PLND → adjuvant durvalumab ×8 (NIAGARA)
- Alternative: neoadjuvant EV + pembrolizumab → RC (EV-304 reported; confirm primary publication)

**If no perioperative ICI:** neoadjuvant GC ×3–4 → RC; adjuvant nivolumab if ypT2–4a or ypN+ (CheckMate 274).

**TMT:** only for **favorable** bladder-preservation candidates — **not preferred** with tumor-related hydronephrosis (HK/IBCG consensus).

### A2 Cisplatin-ineligible, RC-feasible
- Perioperative EV + pembrolizumab → RC (EV-303) if no contraindication to EV
- RC ± carboplatin-based neoadjuvant (weaker evidence than cisplatin)

## Branch B — M0, RC-unfit or declined

### B1 High-risk bladder preservation (includes many hydronephrosis patients)
- **Not ideal TMT candidate** if hydronephrosis, cT3+, multifocal CIS, poor bladder function
- **Definitive concurrent chemoradiotherapy** (not RT alone):
  - Max TURBT → whole-bladder RT 55 Gy/20 fx (preferred schedule) + radiosensitizer
  - BC2001 anchor: 5-FU + mitomycin C concurrent with RT
  - Alternatives: cisplatin, low-dose gemcitabine (center-dependent)
- **Selected cisplatin-fit patients:** NAC → CRT (retrospective series; hydronephrosis associated with worse OS in cohort)
- **Investigational:** pembro + gemcitabine + hypofractionated RT (phase 2 only)
- **Surveillance:** cystoscopy + cytology + CT TAP q3–6 mo × 3 y; salvage cystectomy if localized failure

## Branch C — Unresectable locally advanced and/or M1

Perioperative RC-based trials **do not apply**.

### First-line (if eligible)
1. EV + pembrolizumab (EV-302) — preferred when available
2. Cisplatin-eligible alternatives: nivolumab + GC (CheckMate 901); GC → avelumab maintenance (JAVELIN 100)
3. Cisplatin-ineligible: GC → avelumab; pembro monotherapy if PD-L1+ (KEYNOTE-052)

### Oligometastatic
Systemic therapy backbone ± metastasis-directed RT/surgery in highly selected cases.

## TMT selection criteria (favorable vs not preferred)

**Favorable (IBCG):** unifocal cT2, **no hydronephrosis**, no multifocal CIS.

**Not preferred (HK consensus):** multiple tumors; **cT3+**; extensive/multifocal CIS; **tumor-related hydronephrosis**; suboptimal bladder function; poor surveillance compliance.

**Note:** Zlotta RC vs TMT comparison allowed **no or unilateral** hydronephrosis only — not bilateral.
